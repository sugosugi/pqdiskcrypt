# pqdiskcrypt 简介

版本：`5.4.4`。

## 一句话介绍

pqdiskcrypt 是一款在本地运行的文件加密桌面工具，支持口令与后量子混合公钥保护，可用于移动硬盘、U 盘和文件夹中的文件。

## 发布页简介

pqdiskcrypt 为移动硬盘、U 盘及文件夹中的文件提供本地加密保护，无需浏览器或服务器。它采用 AES-256-GCM 分块认证加密，支持 Argon2id 口令保护和 X25519 + ML-KEM-1024 混合公钥保护，并提供文件名隐藏、卷密钥管理、卷头备份恢复及单文件签名模式。程序使用原生密码后端，执行密钥与路径校验、写入校验和数据冲突保护，默认不将运行日志写入磁盘。

## 功能摘要

- 本地桌面界面，正常加解密无需联网。
- 卷模式逐文件流式处理，适合较大文件。
- 支持口令或公钥解锁，可选隐藏文件名与目录名。
- 支持卷头备份恢复，以及单文件 ML-DSA-87 签名模式。
- 删除原件的加密操作强制写后校验，不自动覆盖已有数据。
- 可按 README 的步骤构建单文件 Windows EXE；构建产物仍需单独验收。

## 发布时应保留的说明

这是文件级加密工具，不是扇区级全盘加密，项目尚未经过独立安全审计。多个密钥槽不是双因素认证；删除密钥槽也不会轮换卷主密钥。使用前应备份数据、卷头和私钥，并先在副本上完成加解密验证。
